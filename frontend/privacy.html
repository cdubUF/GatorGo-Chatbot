Privacy

Do not enter payment cards, identity documents, health information, real booking details, or addresses. The reservation form is for fictional test data only.

The browser keeps your conversation and session token in memory for this tab. The server stores bounded topic context and generated replies in memory for up to 30 minutes of inactivity by default. Restarting the server clears sessions.

For AI responses, the server sends your question, limited context, and relevant project knowledge to OpenAI. After you verify a test reservation, it also sends the hotel name, stay dates, room type, guest count, and status while the reservation is connected. It does not send the guest name, confirmation number, or verification code as reservation context. Disconnect it or start a new conversation to stop sharing. Automated detection of sensitive information is imperfect.

Handoff summaries are displayed to you but are not sent to staff. The application does not make bookings, refunds, charges, or issue keys.

This service runs locally and is not yet configured for public deployment or real staff operations.
