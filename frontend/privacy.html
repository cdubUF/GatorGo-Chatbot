Privacy in this course prototype

Use fictional details only. Do not enter payment cards, identity documents, health information, real booking details, or addresses.

The browser keeps your conversation and session token in memory for this tab. It does not save chat history to local storage. The server stores bounded topic context and generated replies in memory for up to 30 minutes of inactivity by default. Restarting the server clears all sessions.

In optional AI mode, the server sends your current question and limited topic context to OpenAI. Common sensitive patterns are blocked, but automated detection is imperfect. Mock mode makes no model-provider requests.

Handoff summaries contain category and topic, not your full conversation. Only with consent can the summary enter a local demonstration queue. Someone with the configured staff token can view it. Queue entries expire after 30 minutes by default; reset does not recall an already submitted summary.

No employee is notified. No booking, refund, charge, or key is issued. Aggregate counts contain no chat text. This is a local course demo, not a public production service.
