# Anonymous guest perception survey

After watching the same 60-second demo, please answer these optional questions. Do not include your name, room, booking, email, or other identifying details. Participation is voluntary. Responses will be summarized for a class presentation.

Rate each statement from 1 (strongly disagree) to 5 (strongly agree), or leave it blank:

1. The assistant's response was helpful.
2. The assistant came across as friendly.
3. The assistant seemed competent at the demonstrated task.
4. I could trust the assistant's description of what it could and could not do.
5. This assistant would be appropriate in a hotel setting.
6. I would choose to interact with this assistant again.
7. The assistant seemed humanlike.

Overall, how satisfied were you with this interaction? **1 = very dissatisfied, 2 = dissatisfied, 3 = neutral, 4 = satisfied, 5 = very satisfied.**

Optional free response: What would improve this experience? Please avoid personal details.

Use [the results workbook](../outputs/gatorgo-ticket-work/survey-results.xlsx) for anonymous aggregate counts and automatic means, or `survey-results-template.md` for a plain-text worksheet. Average satisfaction = sum of (score × response count) / total valid satisfaction responses. Report the valid response count and missing responses; if no responses exist, report “not collected,” not zero satisfaction. Do not invent respondents or scores. Use the same calculation separately for each rating item. Do not combine the humanlike item with competence or trust as though more humanlike necessarily means better.
