# 60-second demonstration storyboard

| Time | Visible interaction | Presenter narration |
|---|---|---|
| 0–10 seconds | Fresh conversation, local alligator avatar, rule-based demo label | “Meet Gator Go's virtual AI concierge prototype. This demonstration uses fictional hotel information and rule-based answers.” |
| 10–25 seconds | Type “What are the spa hours?” Show answer and sample-source label | “Hotel answers come from a structured knowledge file. Sample policies are visibly labeled; approved facts will be added after review.” |
| 25–45 seconds | Type “My room is dirty and I'm really frustrated.” Show acknowledgement and prepared summary | “When a guest is upset, the assistant acknowledges the concern and recommends human help. A summary is prepared for review.” |
| 45–58 seconds | Type “I want a manager.” Show summary; choose Keep private | “The guest controls whether a summary is submitted. This demo does not notify staff, issue refunds, or change a reservation.” |
| 58–60 seconds | Hold on the action-limit disclosure | “Human employees remain responsible for those decisions.” |

Keep the full app visible at 1440×900 with readable text. Use a clean browser context, no private tabs, real guest data, or credentials. Preserve the AI and demo labels in every crop. The local SVG avatar depicts a friendly alligator with a concierge bow tie; it is decorative next to an explicit virtual-assistant identity.

Review timing aloud; shorten narration if it runs over 60 seconds. `scripts/record-demo.mjs` can capture the scripted interaction without narration. A final narrated/edited version and PowerPoint playback on a second device remain teammate checks. Never label automated recording as instructor-approved or teammate-reviewed.
